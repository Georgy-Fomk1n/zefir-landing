# Зефир и пряник — интернет-магазин

Статический сайт без сборки: открывается любым статическим сервером (`python3 -m http.server`).

| Страница | Файл |
|---|---|
| Главная | `index.html` |
| Каталог | `catalog.html` (`?cat=cake|zefir|pryanik|tort|gift|pp`) |
| Товар | `product.html?id=<id>` |
| Оформление | `checkout.html` |
| Заказ принят | `success.html` |
| Доставка и контакты | `info.html` |

Корзина (шторка) есть на каждой странице и хранится в `localStorage`.

## Где что менять
- **Товары и цены** — `js/products.js`. `price: null` значит «цена по запросу», такой товар в корзину не кладётся.
- **Контакты, график, стоимость курьера** — объект `SHOP` в начале `js/shop.js`.
- **Стили и цвета** — `css/shop.css` (токены в `:root`, тёмная тема тоже там).

## Что ещё не подключено
Заказ сейчас сохраняется только в браузере покупателя, оплата не списывается (`SHOP.demo = true`).
Чтобы принимать настоящие заказы, реализуйте `Shop.submitOrder(order)` в `js/shop.js`:
она получает заказ целиком и должна вернуть `Promise<{ok: true}>`. После этого поставьте `demo: false`.
