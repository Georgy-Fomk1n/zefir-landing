# Зефир и пряник — интернет-магазин (PHP)

Обычный PHP 8 без фреймворка и Composer. Работает на любом хостинге с PHP 8.0+ и расширениями `pdo_sqlite`, `curl`, `mbstring` (на дешёвом shared-хостинге они почти всегда есть).

## Запуск локально

```bash
cp config.example.php config.php
php -S localhost:8080
```

Откройте http://localhost:8080. База заказов создастся сама при первом заказе (`data/shop.sqlite`).

## Установка на хостинг

1. Залейте все файлы в корень сайта (рядом должны лежать `index.php`, `app/`, `api/`, `css/`, `js/`, `images/`).
2. Скопируйте `config.example.php` в `config.php` и впишите настройки.
3. Дайте PHP права на запись в папку `data/`.
4. **Apache:** `.htaccess` уже закрывает `app/`, `data/` и `config.php`. **nginx:** добавьте в конфиг:
   ```nginx
   location ~ ^/(app|data)/ { deny all; }
   location ~ ^/(config\.php|config\.example\.php)$ { deny all; }
   ```

## Страницы

| Страница | Файл |
|---|---|
| Главная | `index.php` |
| Каталог (`?cat=cake\|zefir\|pryanik\|tort\|gift\|pp`, `?sort=asc\|desc`) | `catalog.php` |
| Товар | `product.php?id=<id>` |
| Оформление | `checkout.php` |
| Заказ принят | `success.php` |
| Доставка и контакты | `info.php` |
| Корзина (JSON) | `api/cart.php` |

## Как это устроено

- **Корзина** хранится в PHP-сессии. Цены и названия считает сервер по `app/catalog.php`, браузеру они не доверяются.
- **Заказ** проверяется на сервере (имя, телефон, адрес для курьера, свободный слот, CSRF), сохраняется в SQLite и уходит уведомлением в Telegram и/или на почту.
- **Оплата при получении** (картой или наличными). Онлайн-оплаты нет: её подключают после выбора провайдера.
- На странице «Заказ принят» человек видит только заказ из своей сессии.

## Где что менять

- **Товары и цены** — `app/catalog.php`. `price => null` значит «цена по запросу», такой товар в корзину не кладётся.
- **Контакты, график, цена курьера, слоты, куда слать заказы** — `config.php`.
- **Стили и цвета** — `css/shop.css` (токены в `:root`, тёмная тема там же).
- **Слоты выдачи** — `app/schedule.php` (часы по частям дня).

## Уведомления о заказах

В `config.php`, раздел `notify`:
- **Telegram:** создайте бота у @BotFather, добавьте его в нужный чат, впишите `telegram_token` и `telegram_chat_id`.
- **Почта:** впишите `mail_to` (на хостинге должна работать функция `mail()`).

Если уведомление не ушло, заказ всё равно сохранён; ошибка запишется в `data/error.log`. Заказы лежат в `data/shop.sqlite`, их можно открыть любой программой для SQLite.

## Чего пока нет

- Онлайн-оплаты.
- Админки: заказы смотрят в Telegram или прямо в базе.
- Подтверждения заказа покупателю по SMS или почте.
