# Зефир и пряник — интернет-магазин

Кондитерская на Базовской, Москва. Магазин на **Laravel 12 + React**, который работает на обычном хостинге (PHP + MySQL/SQLite), без VPS и без Node на сервере. Устанавливается на телефон как приложение и присылает push-уведомления.

## Что внутри

| | |
|---|---|
| **Страницы** | Blade: главная, каталог, товар, доставка и контакты. HTML приходит с сервера готовым, поэтому первый экран быстрый и хорошо индексируется. |
| **Корзина и оформление** | React-«острова» (шторка корзины, кнопки покупки, оформление). React и анимации Motion подгружаются после первого кадра. |
| **Админка** | Filament на `/admin`: товары (форматы, цены, фото), заказы (смена статуса в один клик). |
| **PWA** | Установка на экран «Домой», офлайн-страница, кэш статики (service worker `public/sw.js`). |
| **Push** | Владельцу: новый заказ. Покупателю: заказ подтверждён, готов, отменён. Web Push (VAPID), очередь и cron не нужны. |
| **Анимации** | Плавные переходы между страницами (View Transitions, без JS), пружинная шторка корзины, «улёт» картинки в корзину, появление блоков. Учитывают «уменьшить движение». |

## Требования к хостингу

- PHP **8.2+** с расширениями: `pdo_sqlite` (или `pdo_mysql`), `mbstring`, `openssl`, `curl`, `intl`, `gd`, `fileinfo`, `zip`, `xml`
- **HTTPS** (без него не работают установка на экран и push; на хостингах сертификат Let's Encrypt бесплатный)
- Возможность указать корнем сайта папку `public` (иначе сработает корневой `.htaccess`, он уже есть)

## Запуск на своём компьютере

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan shop:admin you@mail.ru      # спросит пароль
php artisan shop:vapid                  # ключи для push
npm run build                           # или npm run dev в соседнем окне
php artisan serve
```

Сайт: http://localhost:8000, админка: http://localhost:8000/admin.

## Установка на хостинг

### Вариант А. Без SSH (проще всего)

На своём компьютере (нужны PHP, Composer, Node, zip, tar):

```bash
ADMIN_EMAIL=you@mail.ru ADMIN_PASSWORD='длинный пароль' \
  bash scripts/release.sh --prepare https://zefiripryanik.ru
```

Получится `dist/zefir-shop.zip`: внутри уже собранный фронтенд, зависимости, `.env` с ключами и база с каталогом и вашим админом. Дальше:

1. Распакуйте архив на хостинге (корень сайта → папка `public`; если так нельзя, оставьте как есть: корневой `.htaccess` перенаправит в `public`).
2. Дайте PHP права на запись в `storage`, `bootstrap/cache`, `database` и `public/uploads`.
3. Откройте сайт и зайдите на `/admin`.

> В архиве лежат секреты (`.env`, база). Не публикуйте его.

### Вариант Б. Через SSH

```bash
bash scripts/release.sh          # чистый архив без секретов (то же делает GitHub Actions)
```

Загрузите архив, распакуйте и выполните на хостинге:

```bash
cp .env.example .env && php artisan key:generate
# в .env: APP_ENV=production, APP_DEBUG=false, APP_URL=https://ваш-домен, при MySQL заполните DB_*
php artisan migrate --force --seed
php artisan shop:admin you@mail.ru
php artisan shop:vapid
php artisan optimize        # кэш конфигов и маршрутов
```

GitHub Actions (`.github/workflows/release.yml`) собирает такой архив при каждом пуше в `main`: Actions → запуск → Artifacts.

### nginx

Корень сайта: `public`. Остальное по [документации Laravel](https://laravel.com/docs/deployment#nginx).

## Как пользоваться

### Товары
`/admin` → **Товары**. Название, раздел, описание, цена, форматы (одно пирожное / набор), метки «Новинка» и «Без сахара», «Нет в наличии», «Только на заказ», порядок, фото.

- Пустая цена = «цена по запросу»: товар виден, но в корзину не кладётся.
- Из загруженного фото сайт сам делает лёгкие WebP-версии 320/480/720 px.
- Любая правка сразу обновляет сайт (кэш страниц сбрасывается сам).

### Заказы
`/admin` → **Заказы**. Статус меняется в списке или кнопками на странице заказа: «Подтвердить», «Готов к выдаче», «Выдан», «Отменить». Покупатель, включивший уведомления, получит push.

### Push владельцу
Откройте `/admin` на телефоне и нажмите **«Включить уведомления»** в шапке. Дальше о каждом новом заказе придёт push (и сообщение в Telegram, если заданы `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`).

**iPhone:** push работает только у установленных приложений (iOS 16.4+). В Safari: «Поделиться» → «На экран “Домой”», затем откройте сайт или админку с иконки и включите уведомления. Для админки есть отдельная иконка «Заказы».

### Настройки
`.env` и `config/shop.php`: телефон, цена курьера, часы работы, слоты выдачи, срок кэша страниц, ключи push, Telegram и почта для заказов.

## Скорость

Измерено Lighthouse (мобильный профиль, сборка `production`, локальный сервер без сжатия):

| Страница | Скорость | Доступность | Практики | SEO | LCP | CLS |
|---|---|---|---|---|---|---|
| Главная | 100 | 100 | 100 | 100 | 0,9 с | 0 |
| Каталог | 90 | 96 | 100 | 100 | 3,6 с* | 0 |
| Товар | 98 | 100 | 100 | 100 | 2,4 с* | 0 |

\* Пессимистичная симуляция Slow 4G; при прикладном троттлинге LCP около 2 с, на хостинге со сжатием и HTTP/2 он ниже. Проверьте на своём хостинге после установки.

Что для этого сделано:

- HTML публичных страниц без сессии и cookie, готовые страницы лежат в кэше (ответ около 10 мс), `ETag` и `stale-while-revalidate`.
- Картинки в AVIF и WebP трёх размеров через `<picture>`, ленивая загрузка, размеры заданы.
- Шрифты свои (только кириллица и латиница), запасные шрифты с подгонкой метрик, предзагрузка главных.
- JS: точка входа около 2,5 КБ (gzip), React и Motion грузятся после загрузки страницы, острова поднимаются раньше срока при касании.
- Видео подгружаются только после первого действия человека и не на медленной сети.
- Долгий кэш хешированных файлов, сжатие, правила в `public/.htaccess`.

Реально подключённый React весит около 70 КБ (gzip). Если захотите ещё легче, его можно заменить на Preact (тот же код, около 4 КБ) одной строкой алиаса в `vite.config.js`.

## Картинки

Исходники лежат в `resources/images-src`. После добавления или замены:

```bash
npm run images      # создаёт AVIF/WebP в public/images и иконки приложения
```

## Тесты

```bash
php artisan test
```

Проверяют слоты выдачи, корзину (включая пересчёт цен на сервере), оформление и его проверки, push-подписки, кэш страниц, доступ в админку.

## Структура

```
app/Models, app/Support        модели, корзина, слоты, push, картинки
app/Http/Controllers           страницы, корзина, оформление, заказ, push
app/Filament                   админка: товары, заказы, виджет
resources/views                Blade-шаблоны
resources/js, resources/css    React-острова, стили, шрифты
public/sw.js, manifest         PWA
scripts/                       images.mjs (картинки), release.sh (сборка для хостинга)
resources/legacy-assets        исходные материалы старого лендинга (не публикуются)
```

## Чего пока нет

- Онлайн-оплаты (оплата при получении). Подключается после выбора провайдера.
- SMS или письма покупателю: только push, если он их включил.
- Для товаров без цены (в макетах стояло «[цена]») нужно заполнить цену в админке.
